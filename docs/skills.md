# Skills

Generated from the bundled skill set. Regenerate with `pnpm docs:generate`; tests detect drift.

This page is the only maintained list of which skills exist. Other pages link here rather than repeating the set, so that a new or renamed skill cannot leave a stale list behind.

`penpair skills install` copies these 11 skills into a project and writes a routing table into its instruction file. Each skill opens with a `## What this owns` section giving its purpose and naming the neighbour that owns the adjacent work; cross-references inside a skill are marked `Next:` (work flows there when this is done) or `Requires:` (read first, it produces this skill's input). See the [glossary](glossary.md) for the words those statements rely on.

| Skill | What it is for |
| --- | --- |
| [`design-judgment`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/design-judgment/SKILL.md) | Choose or critique a screen's hierarchy, density, content and loading, empty or error states. Use for composition decisions and visual critique while respecting approved designs; use penpair-design for Penpot operations and the project's library guidance for component APIs. |
| [`penpair-construct`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-construct/SKILL.md) | Build a Penpot screen or create loading, empty or error variants from an approved frame using the existing library and tokens. Use for design construction and state variants in Penpot; frontend implementation belongs to penpair-handoff. |
| [`penpair-design`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-design/SKILL.md) | Inspect, edit, audit or export a Penpot design with Penpair. Use for Penpot frames, tokens, components, plugin scripts and design screenshots; use penpair-handoff when implementing the design in frontend code. |
| [`penpair-diagrams`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-diagrams/SKILL.md) | Render Penpair journey or integration contracts as Mermaid and editable native Penpot diagrams. Use for map publication, diagram readability, or managed native edits imported as proposals. |
| [`penpair-guide`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-guide/SKILL.md) | Guide someone new to Penpair from first idea to a released design, one phase at a time. Use when the person does not know where to start, what comes next, or where the project stands, and has little design or process background. |
| [`penpair-handoff`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-handoff/SKILL.md) | Implement a frontend from an approved Penpot design, or prepare its design-to-code handoff. Use for component mapping, responsive behavior and design evidence; retain unknown semantics, approved references and comparison requirements. |
| [`penpair-integration-map`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-integration-map/SKILL.md) | Create, review or reconcile Penpair integration maps connecting a user journey and design evidence to routes, components, state, data and implementation verification. |
| [`penpair-journey-map`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-journey-map/SKILL.md) | Create, review or update a Penpair user journey map. Use when a feature needs agreed user goals, states, transitions and recovery before integration or implementation. |
| [`penpair-release`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-release/SKILL.md) | Plan, resume, verify and finalize a native Penpot product design release. | [`penpair-setup`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-setup/SKILL.md) | Install Penpair through assisted or manual steps, connect an assistant to Penpot, or repair a failing doctor check, suspended plugin or missing configuration. Use for first setup and connection repair; use penpair-design for work in a connected design file. |
| [`penpair-verify`](https://github.com/niklas-westman/penpair/blob/main/packages/core/skills/penpair-verify/SKILL.md) | Verify a frontend against an approved Penpot design using Penpair Reflection Check. Use to check visual parity, investigate design mismatches or recheck an implementation after fixes with real browser screenshots and observed application state. |

Skills are listed alphabetically, which is the order `penpair skills install` reports them in. It is not a sequence to work through: read the one that matches the task, and follow its marked edges from there. If you do not know where to start, use the guide, which reads the project and names the next phase. [Check skill discovery and behavior](skill-validation.md) before relying on an installed set.
